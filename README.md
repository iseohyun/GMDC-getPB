# GMDC 수영 기록 관리 시스템 (Swim Records Manager)

수영 클럽 회원의 종목별 기록(핀접영, 핀자유, 자유형, 배영, 평영, 접영)을 관리하고 실시간으로 편집할 수 있는 웹 애플리케이션입니다.

## 📌 주요 기능

1. **기록 테이블 및 실시간 숫자 편집**
   - 2026-01-01 기준 37명 회원의 기본 데이터 탑재
   - 기록 입력란에 **숫자 및 소수점(.)만 입력 가능**하도록 엄격한 유효성 검사 적용
   - 방향키(↑↓←→), Enter, Tab 키를 통한 엑셀 스타일 셀 이동 지원

2. **엑셀(Excel) 연동 기능**
   - **엑셀 복사**: 클릭 한 번으로 표 전체를 TSV 형식으로 복사하여 엑셀/스프레드시트에 바로 붙여넣기(`Ctrl+V`) 가능
   - **엑셀 붙여넣기**: 엑셀에서 복사한 다중 행/열 데이터를 웹 표의 원하는 위치에 바로 붙여넣기 지원
   - **CSV 내보내기**: 한글 깨짐 없는 UTF-8 BOM 인코딩 CSV 파일 다운로드

3. **스마트 통계 및 하이라이트**
   - 전체 인원, 남/여 성비, 기록 등록 회원 수 실시간 집계
   - 각 종목별(핀접영, 핀자유, 자유형, 배영, 평영, 접영) **최고 기록(Fastest) 골드 뱃지 및 별표(★) 자동 하이라이트**

4. **검색, 필터링 및 정렬**
   - 이름 또는 연령 실시간 검색
   - 성별(전체, 남성, 여성) 및 기록 보유자 필터링
   - 컬럼 헤더 클릭 시 오름차순/내림차순 정렬

5. **자동 저장 및 관리**
   - 브라우저 로컬 저장소(`localStorage`)를 통한 데이터 자동 보존
   - 신규 회원 추가 및 기존 회원 삭제 기능
   - [초기화] 버튼을 통해 기본 데이터(37명)로 언제든지 복구 가능

## 🚀 실행 방법

브라우저에서 `index.html` 파일을 바로 열거나, 로컬 웹 서버(VSCode Live Server, `npx serve .` 등)를 통해 실행할 수 있습니다.
