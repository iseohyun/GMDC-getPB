# GMDC 수영 기록 관리 시스템 (Swim Records Manager)

수영 클럽 회원의 종목별 기록(핀접영, 핀자유, 자유형, 배영, 평영, 접영)을 관리하고 실시간으로 편집할 수 있는 웹 애플리케이션입니다.

## 📌 주요 기능

1. **기록 테이블 및 실시간 숫자 편집**
   - 2026-01-01 기준 37명 회원의 기본 데이터 탑재
   - 기록 입력란에 **숫자 및 소수점(.)만 입력 가능**하도록 엄격한 유효성 검사 적용
   - 방향키(↑↓←→), Enter, Tab 키를 통한 엑셀 스타일 셀 이동 지원

2. **엑셀(Excel) 연동 기능**
   - **엑셀 복사**: 클릭 한 번으로 표 전체를 TSV 형식으로 복사하여 엑셀/스프레드시트에 바로 붙여넣기(`Ctrl+V`) 가능
   - **엑셀 붙여넣기**: 엑셀에서 복사한 다중 행/열 데이터를 웹 표의 원하는 위치에 바로 붙여넣기 지원
   - **CSV 내보내기**: 한글 깨짐 없는 UTF-8 BOM 인코딩 CSV 파일 다운로드

3. **단체전 최적 조합 및 선발 고정 (Fixed Relays)**
   - **5개 단체전 종목**: 혼성 핀계영 300m(240세↑), 남/여 계영 200m(160세↑), 남/여 혼계영 200m(160세↑)
   - **선발 명단 고정(`🔒 고정`) / 실시간 자동 추천(`⚡ 자동`) 토글**: 대회 출전 확정 멤버를 지정하여 보존
   - **시나리오 작성 시 고정 선수 자동 제외**: 중복 차출 및 이중 배정 방지 알고리즘 적용
   - **개인전 및 기록표 연동**: 출전 확정된 단체전 종목 뱃지(`[🔒 혼성핀]`, `[🔒 남계영]` 등) 표시
   - **엑셀 원클릭 복사**: 대회 제출 양식에 맞춘 TSV 클립보드 복사 지원

4. **검색, 필터링 및 정렬**
   - 이름 또는 연령 실시간 검색
   - 성별(전체, 남성, 여성) 및 기록 보유자 필터링
   - 컬럼 헤더 클릭 시 오름차순/내림차순 정렬

5. **자동 저장, 히스토리 검증 및 DB 스냅샷**
   - 성인부(41명: A팀 30명, B팀 11명) 및 학생부(20명) 전용 데이터베이스 구축
   - 브라우저 로컬 저장소(`localStorage`) 및 Firebase Firestore 클라우드 실시간 자동 동기화
   - **DB 스냅샷 저장 및 버전 복원**: 원하는 시점의 전체 DB 상태를 스냅샷으로 영구 저장하고 언제든지 원클릭으로 복원 가능
   - **히스토리 데이터 무결성 검증**: 변경 이력 로그를 누적 재현하여 현재 DB와 100% 정합성 검증

## 🚀 실행 방법

브라우저에서 `index.html` 파일을 바로 열거나, 로컬 웹 서버(VSCode Live Server, `node server.js` 등)를 통해 실행할 수 있습니다.
